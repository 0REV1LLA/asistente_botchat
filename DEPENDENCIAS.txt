Uso: framework principal del proyecto; maneja vistas, rutas, sesiones, plantillas y ORM.

django-simple-chatbot==0.0.9
Uso: dependencia auxiliar del ecosistema del chatbot; queda como soporte del sistema de mensajería.

Uso: útil si se exponen endpoints API o se amplían respuestas JSON del chat.

Uso: soporte para procesamiento de lenguaje natural si se agregan reglas o análisis de texto.

Uso: carga variables de entorno desde el archivo .env para configuración local.

mysqlclient==2.2.8 (opcional)
